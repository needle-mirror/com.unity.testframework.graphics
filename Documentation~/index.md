# Graphics Test Framework package

Render test images from your project and test them against reference images to detect rendering regressions across platforms, graphics APIs, and hardware configurations.

The Graphics Test Framework package extends the [Unity Test Framework](https://docs.unity3d.com/Manual/test-framework/test-framework-introduction.html), which uses a Unity integration of the open-source [NUnit](https://docs.nunit.org/) unit testing library.
