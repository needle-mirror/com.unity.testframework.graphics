# Graphics Test window Logs tab reference

The Logs tab of the Graphics Test window displays the logs from test runs.

| **Property** | **Icon** | **Description** |
|:---|:---|:---|
| **Filter logs by name** | <span class="icon-EditorUI-Search" aria-label="Search"></span> | Filters log entries by a search term. |
| **Open File** | N/A | Opens the log file in an external text editor. |
| **Scroll to Latest** | N/A | Scrolls to the most recent log entry at the bottom of the list. |
| **Clear** | N/A | Clears all log entries from the list. |
