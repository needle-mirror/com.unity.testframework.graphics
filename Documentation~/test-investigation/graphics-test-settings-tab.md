# Graphics Test window Settings tab reference

The Settings tab displays the properties of a Graphics Test Build Settings asset. Use the settings to customize how Unity prepares graphics tests and the Graphics Tests window.

Unity creates a default asset automatically. If it's missing, from the main menu, select **Assets** > **Create** > **Graphics Test Framework** > **Graphics Test Build Settings** to create one. The asset must be in a **Resources** folder in your **Project** window.

For more information, refer to [Customize tests](../build-customization/customize-a-test.md).

| **Property** | **Description** |
|:---|:--|
| **Settings** | Sets the Graphics Test Build Settings asset file that Unity uses and displays in this window. For more information, refer to [Graphics Test Build Settings Inspector window reference](graphics-test-build-settings-inspector.md). |
