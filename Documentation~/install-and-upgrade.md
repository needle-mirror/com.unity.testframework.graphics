# Install the Graphics Test Framework package

To install the Graphics Test Framework package, follow these steps:

1. From the main menu, select **Window** &gt; **Package Manager** to open the **Package Manager** window.
2. In the **Sources** section, select **Unity Registry**.
3. Select **Graphics Test Framework** from the list of packages.
4. Select **Install**.

Unity creates a graphics test build settings asset in the **Assets/Resources** folder in the **Project** window. For more information, refer to [Graphics Test Build Settings Inspector window reference](test-investigation/graphics-test-build-settings-inspector.md).
